# Unemployment Analysis with Python

## Objective

The objective of this project is to analyze unemployment data in India and identify regional and time-based unemployment trends. The project also studies the impact of COVID-19 on unemployment rates.

## Dataset

The dataset contains unemployment-related information for different regions of India.

Important columns include:
- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Loaded and explored the unemployment dataset.
- Checked dataset shape, data types, and missing values.
- Performed descriptive statistical analysis.
- Calculated region-wise average unemployment rates.
- Analyzed month-wise unemployment trends.
- Created time-series analysis for selected regions.
- Identified the Top 10 regions with the highest average unemployment.
- Performed correlation analysis.
- Created a correlation heatmap.
- Compared unemployment rates before and during the COVID-19 period.

## Visualizations

The project includes:
- Region-wise average unemployment bar chart
- Month-wise unemployment trend
- Time-series chart for three regions
- Top 10 regions bar chart
- Correlation heatmap
- Pre-COVID vs Post-COVID comparison chart

## Conclusion

The analysis helps understand unemployment patterns across different regions and time periods in India. It also provides insights into changes in unemployment during the COVID-19 period.
