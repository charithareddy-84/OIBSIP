# Car Price Prediction with Machine Learning

## OASIS INFOBYTE Data Science Internship – Task 3

**Presented by:** Charitha Reddy Mettu

## Objective

The objective of this project is to predict car prices using machine learning techniques based on different features of cars.

## Project Overview

In this project, the car price dataset was analyzed and prepared for machine learning. Exploratory Data Analysis (EDA) was performed to understand the patterns and relationships between different car features and price.

Two regression models were trained and compared:

- Linear Regression
- Random Forest Regression

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Steps Performed

1. Loaded and explored the dataset.
2. Checked data types, missing values, and duplicate records.
3. Cleaned the dataset.
4. Performed Exploratory Data Analysis.
5. Visualized car price distributions and feature relationships.
6. Encoded categorical features into numerical values.
7. Created a correlation heatmap.
8. Split the dataset into training and testing sets.
9. Trained Linear Regression and Random Forest Regression models.
10. Evaluated the models using MAE, RMSE, and R² Score.
11. Compared the models and selected the better-performing model.
12. Analyzed feature importance.

## Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

The model with lower MAE and RMSE and higher R² Score was considered the better-performing model.

## Conclusion

This project demonstrates how machine learning can be used to predict car prices based on vehicle characteristics. The comparison of different regression models helped identify the better-performing model for the dataset.
