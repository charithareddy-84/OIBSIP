# Iris Flower Classification

## OASIS INFOBYTE Data Science Internship - Task 1

### Objective

To build a machine learning classification model that predicts the species of an iris flower based on its physical measurements.

## Project Description

This project uses the Iris dataset to classify iris flowers into three species:

- Setosa
- Versicolor
- Virginica

The project includes data exploration, data visualization, feature selection, model training, and model evaluation.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

Two classification models were used:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)

## Data Analysis and Visualization

The dataset was explored using:

- Dataset shape
- Data types
- Missing value checking
- Descriptive statistics
- Pairplot
- Box plots

## Model Evaluation

The models were evaluated using:

- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score

Both Logistic Regression and KNN achieved the same accuracy on the test dataset.

Logistic Regression was selected as the preferred model because it provides the same predictive performance with a simple and interpretable approach.

## Project Files

- `Iris_Flower_Classification.ipynb` - Complete Jupyter Notebook containing the project.

## Conclusion

The Iris Flower Classification project successfully classifies iris flowers into Setosa, Versicolor, and Virginica species based on their physical measurements using machine learning classification algorithms.
